ICPSR 20541
National Social Life, Health, and Aging Project (NSHAP): Round 1, [United States], 2005-2006

da20541-0008 is a zipped archive of 4 files that contains the original Stata data files with
extended and nonextended missing values provided by the P.I.


Files with extended missing values:

1) nshap_w1_core.dta
2) nshap_w1_network.dta

Files with nonextended missing values:

1) nshap_w1_core_noextended.dta
2) nshap_w1_network_noextended.dta


These data files are being distributed exactly as they arrived from the depositor.
